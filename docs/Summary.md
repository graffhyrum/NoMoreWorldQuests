# Summary

## Goals of the Addon
- Ability to completely turn off the visibility of world quests. 
- Visible off from:
  - minimap
  - map (Blizzard filter exists; addon still enforces when suppression is on)
  - talking heads (vignettes)
  - objectives
- Button on minimap to easily turn them back on. 
- Flashes if you're in an active WQ. 
- While suppression is on: all WQ UI invisible except manual turn-in / completion UI.
